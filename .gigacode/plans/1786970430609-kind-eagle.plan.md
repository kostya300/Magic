# План: Добавление характеристик товаров (specs)

## Контекст
- Frontend (`Tabs.js`) уже ожидает `product.specs` как массив `{label, value}`
- Backend не содержит полей для характеристик
- Характеристики зависят от категории (разные наборы для разных категорий)
- Используется JSONB поле для гибкости

## Изменения

### 1. Backend — Модель (app/models/products.py)
- Добавить JSONB поле `specs` (по умолчанию пустой словарь)

### 2. Backend — Схема (app/schemas.py)
- Добавить `specs: dict | None = Field(default=None, description="Характеристики товара")` в `Product` и `ProductCreate`

### 3. Backend — Миграция (Alembic)
- Создать миграцию для добавления колонки `specs` в таблицу `products`

### 4. Frontend — UI (опционально)
- Папки `specifications_components_for_tabsjs` и CSS созданы
- Текущая табличка в Tabs.js достаточно простая — используем её

## Файлы для изменения
- `app/models/products.py`
- `app/schemas.py`
- Alembic миграция

## Верификация
1. `alembic upgrade head` — применить миграцию
2. Запустить API и проверить, что `GET /products/{id}` возвращает `specs`
3. Проверить фронтенд — вкладка "Характеристики" отображает данные
